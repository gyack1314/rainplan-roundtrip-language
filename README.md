# 雨洪方案从平面编辑写回规划语言

此项目使用本地合成资料描述相关工程场景。`inputs/` 中的语言源文本和数据契约资料可用于本地演练，不对应真实台站、城区或控制设备。

## 交换约定

规划文本的 `parcel` 定义地块，`prototype` 提供参数化地块定义，`use` 以稳定业务身份实例化。`import` 是工作区相对路径。线路用 `connect id: 对象.端口 -> 对象.端口`；`off id` 在情景中显式停用线路。情景可覆盖属性、端口配置和线路。`in` 和 `out` 的端口必须方向相反且类型相同，输入端同一情景最多一条有效入线。编辑文件的 `target` 由对象身份及情景标识构成，`scope` 区分实例及公共声明。编辑者声明的操作以前一视图为事实基准，编辑器允许将一组关联修改同时提交。`workspaces.json` 标识打开方案时的版本以及独立演化的两份当前文本。

## 资料检查

使用 CPython 3.11.2 标准库，无需安装第三方包。资料检查入口可以列出任意资料目录的路径、文件大小与原始字节摘要，并检查 JSON 和文本编码。

```sh
python3 inspect_inputs.py inputs
python3 -m unittest discover -s tests -v
```

目前入口负责资料清点，源语言文件按原始文本保存，尚未提供语言编译及执行入口。
